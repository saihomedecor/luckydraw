# 🎉 Lucky Draw System

A simple Lucky Draw web app built with **HTML, CSS, JavaScript**.  
✔ Add Name & Phone Number  
✔ Store data in browser (localStorage)  
✔ Pick a random winner 🎲  

## 🚀 How to Run
1. Download this folder as ZIP & extract.
2. Open `index.html` in your browser.
3. Start adding participants and run the lucky draw!
